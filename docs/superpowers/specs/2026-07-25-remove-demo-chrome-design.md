# FitPilot 演示界面精简设计

日期：2026-07-25

## 目标

移除桌面侧栏底部的“数据仅存本地浏览器 / Demo · 2026”说明，并完整移除“设置”功能入口和页面，让公开演示界面更简洁。

## 改动范围

- `Sidebar` 不再渲染底部演示说明。
- 导航配置不再包含 `settings`，`TabKey` 同步移除该取值。
- `App` 不再导入或渲染 `SettingsPage`。
- 删除不再可达的 `SettingsPage.tsx`。
- 保留应用启动时清理旧版浏览器 `settings` 数据的兼容逻辑，避免历史敏感配置残留。

## 验收

- 桌面侧栏没有演示水印。
- 桌面和移动导航均没有“设置”。
- TypeScript 不存在 `settings` 页面引用。
- 前端测试、lint 和生产构建通过。
- 修改推送到现有功能分支并重新部署 Vercel Preview。
